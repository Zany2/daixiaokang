      <h3 id="oss-dtoken-title">DToken-Go</h3>
      <p class="oss-project-summary">为 Go 应用提供统一的登录、权限与会话管理。</p>
      <p class="oss-project-description">将 Token 生命周期、角色权限和多端登录管理集中到一个可插拔的认证内核，支持 SSO、OAuth2，并可集成到多种 Go Web 框架。</p>
      <div class="oss-features" role="list" aria-label="DToken-Go 主要能力">
        <span class="oss-feature" role="listitem">Token 与 Session 管理</span>
        <span class="oss-feature" role="listitem">角色权限与多端登录</span>
        <span class="oss-feature" role="listitem">SSO / OAuth2</span>
      </div>

      <h3 id="oss-browserflow-title">BrowserFlow</h3>
      <p class="oss-project-summary">让浏览器里的重复操作，成为可复用的工作流。</p>
      <p class="oss-project-description">集成 Automa 工作流，支持 Windows 本地执行与服务端多客户端调度，提供定时任务、执行记录及结果回传，并可导出供大模型调用的 Skill。</p>
      <div class="oss-features" role="list" aria-label="BrowserFlow 主要能力">
        <span class="oss-feature" role="listitem">本地执行与远程调度</span>
        <span class="oss-feature" role="listitem">定时任务与执行记录</span>
        <span class="oss-feature" role="listitem">LLM Skill 集成</span>
      </div>

      <h3 id="oss-rustwing-title">RustWing</h3>
      <p class="oss-project-summary">为 Rust 实时服务构建可扩展的 WebSocket 基础。</p>
      <p class="oss-project-description">提供会话生命周期、心跳、有界发送队列与分布式路由，支持 Axum 接入及 Redis 集群适配。项目处于早期阶段，公开 API 仍在演进。</p>
      <div class="oss-features" role="list" aria-label="RustWing 主要能力">
        <span class="oss-feature" role="listitem">会话管理与心跳检测</span>
        <span class="oss-feature" role="listitem">有界队列与背压控制</span>
        <span class="oss-feature" role="listitem">多节点路由与消息投递</span>
      </div>
