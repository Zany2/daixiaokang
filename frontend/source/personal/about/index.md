  <section class="ab2-section" aria-labelledby="about-stack">
    <h2 id="about-stack"><span aria-hidden="true">03</span> 小站是怎样搭起来的</h2>
    <p class="ab2-section-lead">页面由 Hexo 生成，互动功能由自己的后端提供。这里简单介绍组成它的几个部分。</p>
    <dl class="ab2-stack">
      <div><dt>页面与主题</dt><dd><strong>Hexo · Fomalhaut</strong><p>使用 Markdown 写作，配合基于 Butterfly 的 Fomalhaut 主题，按自己的需要调整页面和交互。</p></dd></div>
      <div><dt>互动与数据</dt><dd><strong>Python · FastAPI · PostgreSQL · Redis</strong><p>后端提供评论、留言、AI 助手与网站统计等功能。</p></dd></div>
      <div><dt>图片与视频</dt><dd><strong>腾讯云 COS · EdgeOne</strong><p>图片和视频放在对象存储中，通过 CDN 加速加载；网页也通过 EdgeOne 加速访问。</p></dd></div>
      <div><dt>部署与维护</dt><dd><strong>Docker Compose · Nginx · HTTPS</strong><p>容器运行前后端服务，Nginx 提供站点访问与接口转发，源站证书自动检查并续期。</p></dd></div>
    </dl>
  </section>
