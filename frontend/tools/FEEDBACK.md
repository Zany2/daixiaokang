# 自建评论与留言板

以下路径与命令均以 `frontend/` 为基准。站点启动见[根 README](../../README.md)，后端接口与数据模型见[后端 README](../../backend/README.md)。

文章详情页使用 `themes/fomalhaut/layout/includes/feedback.pug` 的评论面板；留言板由 `source/comments/index.md` 使用 `guestbook` 页面类型生成。旧信封插件已关闭，Twikoo 默认不加载，独立页面不挂载文章评论。

## 本地连接

`_config.fomalhaut.yml`：

```yaml
feedback:
  enable: true
  api_base: /api
  local_api_base: http://localhost:8000/api
  request_timeout_ms: 12000
```

通过 `localhost` / `127.0.0.1` / `::1` 访问前端时，使用 `local_api_base`；其他主机名和 IP 使用 `api_base`。正式站 `https://daixiaokang.com` 走同源 `/api`，由服务器保留 `/api` 路径并转发到 FastAPI 的 8000 端口。改域名不影响评论的 `article_key` 和已保存数据。

前端默认开发来源 `http://localhost:4000` / `http://127.0.0.1:4000` 已在后端默认 CORS 配置中；使用其他端口或 IPv6 时需同步后端 `CORS_ORIGINS` 和 `TRUSTED_HOSTS`。手机真机访问开发电脑的局域网地址时，`api_base` 需临时填写开发电脑的后端完整地址，并在后端允许对应的前端来源；手机自身的 localhost 无法访问电脑后端。

修改主题配置、新增 Hexo helper 或替换留言板生成方式后，需要重新生成页面或重启开发服务。

## 展示与交互

- 文章评论：上方填写昵称、选填邮箱和内容，下方显示无头像列表；根评论每页 30 条，每层先显示 3 条回复。
- 点击“查看更多回复”才请求该楼层下一批 10 条；支持回复其他回复、取消回复和按 ID 去重。
- 回复始终归入对应根评论，按创建时间排列；刚发表的回复立即显示，不要求它位于前 3 条预览中。
- 根评论使用页号分页，显示根评论总数、上一页、下一页和省略页码；回复使用独立游标，“查看更多回复”仍只在点击后查询。
- 发表回复时保留当前列表的加载请求，并合并刚发表的回复；不会因取消请求而让列表停留在加载状态。
- 留言板：上方填写信息，下方显示普通每页 30 条的列表，不显示头像或回复按钮。
- 评论和留言列表都显示总数，支持上一页、下一页和页号选择。7 页以内显示所有页码；更多页显示首尾与当前页附近页码，中间用省略号表示。只有一页时也显示分页区域，上一页和下一页禁用。
- 选择页码后滚动至列表开头，避免停留在上一页列表底部；手机端保留上下布局。
- 两种列表每页最多展示 30 条；后端确认刚发表的根评论或留言后移除临时补入项，避免总数重复增加。当前页超过最新总页数时自动加载有效尾页。
- 评论页码查询依赖后端提供的 `page`、`total`、`total_pages`，部署时保持前后端接口版本一致。
- 两种页面的发表入口共享前端 10 秒倒计时；`429` / `503` 时读取后端 `Retry-After`。
- 后端返回字段校验错误 `422` 时释放本次前端预留的发表倒计时，修正后可立即重新提交。
- 昵称及内容按照 Unicode 字符计数，与后端的 50 / 2000 字符限制一致，emoji 不重复计数。
- 提交失败保留填写内容；发表成功只清空内容框，立即显示新记录，再刷新根评论或留言第一页。
- 临时保留刚发表的记录，防止较早发出的列表请求覆盖新记录；后端列表不使用 Redis 响应缓存。
- 草稿仅在当前页面会话的内存中暂存，用于 PJAX 往返恢复；不写入 localStorage，不公开邮箱。
- 访客内容和昵称通过 `textContent` 渲染，保留换行，不执行 HTML。
- 提供加载、空列表、失败重试和屏幕阅读器提示；明暗模式与主题色共享，移动端单栏。
- 留言板没有大图横幅，但全页图片上的顶部导航使用白色文字，并沿用菜单发光开关；滚动后的固定导航继续使用主题原有样式。
- PJAX 离开时撤销旧页面请求、事件处理器，避免串页或重复发表；倒计时在站内换页时保留。
- 刷新列表期间暂停加载楼层回复，旧回复请求不能解除或覆盖新请求的状态。
- 表单在交互脚本挂载后才启用发表按钮，防止脚本尚未加载时将内容作为普通 GET 表单提交。

样式文件：`source/css/feedback.css`。交互文件：`source/js/feedback.js`。修改后同步对应资源的 `?v=` 版本号。
