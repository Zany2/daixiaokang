# 2、技术栈
 * 博客框架：Hexo 6.3.0
 * 主题：Butterfly 4.3.1
 * 源码仓库：Github
 * 托管与部署：本网站采用多线部署，包括Vercel + Netlify + Cloudflare + Railway + Fleek + Render + Zeabur + Github Pages 等
 * 评论系统：Twikoo系统 + Vercel部署 + MongoDB提供存储服务
 * CDN： 七牛云
 * SEO优化：谷歌 + 必应 + 百度
 * 音乐平台：hexo-tag-aplayer + MetingJS
 * 开发语言：HTML5 + CSS3 + JavaScript + Pug + YML等

# 3、网站记录
 * 大学的时候就想搭一个自己的网站，但是迫于自己技术栈的限制没有成功。那个时候主要学习的还是linux系统和kali渗透，接触后端语言是从大二开始，那个时候Golang还没有现在这么火，于是就自学了Go和Java。但是看到学前端的同学可以制作这么炫酷的网页真的非常羡慕。于是在工作的第一年抽出时间搭了自己的网站。使用hexo的原因是因为框架偏前端，易上手。刚开始的时候也尝试过搭建一个可管理的网站，搜了很多模板。但是前端的效果都没有达到自己的预期。虽然现在网站使用的技术个人感觉比较简单，但是效果还是可以接受的。在这里非常感谢网站开源的作者<font color=blue>Fomalhuat</font>，借用他的开源版本搭建了自己的网站。
